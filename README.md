# eso-website-assets

Skripte für www.eso-anlage.de, ausgeliefert über jsDelivr.

- `hero3d.js` – interaktive 3D-Darstellung der ESO-Anlage im Hero-Bereich (enthält three.js, MIT-Lizenz)
- `eso.min.js` – Seitenskript (Menü, Animationen, Darstellung der Anlage), minifiziert

Einbindung mit fester Version:

```html
<script src="https://cdn.jsdelivr.net/gh/kevinpxm/eso-website-assets@v1.0.0/eso.min.js" defer></script>
```

Die Dateien sind aus dem Projekt eso-markenupdate erzeugt und werden nicht von Hand geändert.
